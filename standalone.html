📖 Формулы диагоналей

Прямоугольник
d = √(a² + b²)
Параллелограмм
d₁ = √(a² + b² − 2ab·cos α)d₂ = √(a² + b² + 2ab·cos α)
d₁² + d₂² = 2(a² + b²)
Ромб
d₁² + d₂² = 4a²a = √((d₁/2)² + (d₂/2)²)
Правильный n-угольник
dₖ = a · sin(kπ/n) / sin(π/n)
k = 2, 3, ..., ⌊n/2⌋
